# Lyra 1.4.0 · 阅读统计

> 本次更新带来**永久累计的阅读统计**页面,并修掉了两个"该读的没读"的问题。

## ✨ 新功能:阅读统计(圆盘 + 波浪条)

- **实时剧情页上方**新增「阅读统计」按钮(和实时监控面板绑在一起,不会被剧情列表顶下去),点击后**全屏覆盖**打开统计页,左上角「返回」回到原页面
- **永久累计**:这台游戏一共读了多少字 / 多少句 / 读了多少时间,**关游戏、关软件、重装都不会丢**
  (记录在 `%LOCALAPPDATA%\Lyra\readstats.json`,按游戏分开记)
- 图表:
  - **圆盘图** —— 最近 7 天每天读了多少字,占比一目了然
  - **波浪条** —— 最近 14 天柱状走势,悬停显示当天字数
  - **各游戏排行** —— 读得最多的排前面,带进度条
  - 平均速度(字/分)、连续阅读天数、首次开始 / 最近一次
- 「清零这台」只清当前游戏,其它游戏记录不受影响

## 🐞 修复

- **正常台词被误过滤**:台词里只要出现「商店」「记忆」「设置」这类界面关键词,整句就会被丢掉。
  原因是界面词匹配排在"这是不是台词"之前。现在**先认台词(带引号的)**,面板/菜单文字照旧被拦,过滤能力不变。
- **选择/卡牌界面不再乱点**:几秒内连着出现多条短句 → 判定为选项画面,自动点击**暂停 25 秒**让玩家自己选,
  状态栏会提示原因。

## 📝 关于「自定义 UI」

本来这一版想做成"整个界面都能自己设计"(拖组件、改侧栏/顶栏/圆角/密度、浏览器/独立窗口设计器),
**实现过程中遇到问题,已回滚,仍在推进中**:主要是新开一个全屏设计窗口需要改窗口宿主(`player.cpp`)并重新编译,
连续两次改坏了编译,为保证程序可用先撤掉了。这部分会在后续版本继续做,计划是:

1. 窗口宿主增加最小尺寸保护(顺带解决"窗口偶尔变成一条小缝")
2. 宿主支持 `--designer`:独立全屏设计窗口 + 退出按钮
3. 设计器页面开放接口,布局可导出/导入分享
