# Lyra 1.4.0 · 阅读统计

> 这一版加了**永久累计的阅读统计页**(圆盘图 + 波浪条 + 排行),并修掉了两个"该读的没读"的问题。

## ✨ 新功能:阅读统计

- **入口**:实时剧情页 → 实时监控面板标题栏右侧的「◔ 阅读统计 · N 字」按钮(数字就是这台游戏的累计字数,实时增长)
- 点一下**全屏覆盖**打开统计页,不会挤占剧情列表;左上角「返回」或 `Esc` 回到原页面
- **永久累计**:关游戏、关软件、重装都不会丢。记录位置 `%LOCALAPPDATA%\Lyra\readstats.json`,**按游戏分开记**
- 统计内容:
  - 累计字数(大字滚动)/ 累计句数 / 阅读时长 / 平均速度(字/分)
  - 首次开始 / 最近一次 / 连续阅读天数 / 今日已读
  - **圆盘图**:最近 7 天每天的占比
  - **波浪条**:最近 14 天走势,悬停看当天字数
  - **各游戏排行**:读得最多的排前面
- 「清零这台」只清当前游戏(二次确认)

### 进出动画

- 进入:背景淡入 → 卡片依次升起 → 圆盘自己画出来 → 波浪条从底部长出 → 数字滚动
- 退出:卡片依次下沉缩小淡出,播完才关闭
- 系统开启「减少动态效果」时全部动画自动关闭

## 🐞 修复

- **正常台词被误过滤**:台词里只要出现「商店」「记忆」「设置」这类界面关键词,整句就会被丢掉
  (日志里能看到 `未读[界面词(商店)]: 「就是有很多商店聚集的地方！…」`)。
  原因是界面词匹配排在"这是不是台词"之前。现在**先认台词(带引号的)**,面板/菜单文字照旧被拦,过滤能力不变。
- **选择/卡牌界面不再乱点**:几秒内连着出现多条短句 → 判定为选项画面,自动点击**暂停 25 秒**让玩家自己选,状态栏会提示原因。
- **统计偶尔丢最后几秒**:写盘节流原本 5 秒,直接杀进程会丢掉刚读的那几句;现在改为 1 秒节流 + 攒 3 句即写 + 后台每秒兜底。

## 📝 关于「自定义 UI」

这一版原本还想做"整个界面都能自己设计"(拖组件、改侧栏/顶栏/圆角/密度、独立设计窗口),
**实现中遇到问题已回滚,仍在推进中** —— 主要是"另开一个全屏设计窗口"需要改窗口宿主(`player.cpp`)并重新编译,
连续两次改坏编译,为保证程序可用先撤掉了。后续计划:

1. 窗口宿主加最小尺寸保护(顺带解决"窗口偶尔变成一条小缝")
2. 宿主支持 `--designer`:独立全屏设计窗口 + 退出按钮
3. 设计器开放接口,布局可导出 / 导入分享
