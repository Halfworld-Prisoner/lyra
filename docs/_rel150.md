# Lyra 1.5.0 · 跨远程访问(研发中)

> 这一版新增 **跨远程访问**:手机 / 另一台电脑在同一个网络里就能打开 Lyra,不需要任何外部服务器。
> **该功能已可使用,但仍是半成品,仍在研发中** —— 详见下方「研发中」一节。

## ✨ 新功能:跨远程访问(局域网直连)

- **开关位置**:设置 → 最上方「扩展模块 · 跨远程访问」
- 打开后,**顶栏搜索框旁边**出现「⇄ 跨设备」入口,点开是一个独立页面:
  - **链接状态** —— 服务 / 端口 / 安全码 / 防火墙 + 可用地址(自动标出「推荐」)+ 一键放行防火墙
  - **安全码** —— 4 位安全码,手机首次访问输入一次,之后 30 天免输;可随时换码
  - **设置** —— 远程端口(只读锁死)、启动时自动开启、允许电脑访问、允许远程改设置
- **四种连接方式都会自动识别**,并给出最优路线:
  | 方式 | 说明 |
  |---|---|
  | 电脑开热点,手机连 | 最可控,不依赖路由器 |
  | 手机开热点,电脑连 | 电脑拿到手机网段地址 |
  | 同一 WiFi 路由器 | 手机访问电脑的局域网地址 |
  | USB 网络共享 | 免 WiFi,最稳最快 |
- **权限控制**:默认**不允许**远程修改设置(关着的时候,远程只能查看与朗读;服务端直接拒绝,不是靠前端藏按钮)
- **不用服务器**:全部走局域网直连;手机端是自适应页面,手机窄屏用抽屉式侧栏,电脑访问则显示桌面版排布

## 🚧 研发中(如实说明,这一版还不完整)

跨远程访问**已实现基本连通与遥控**,但下面这些还在做:

1. **互动与交互** —— 把电脑上正在显示的画面同步到手机上(当前只有文字与控制,还没有画面同步)
2. **手机端 UI 继续打磨** —— 视觉与操作还要再优化,目标是"手机上也好用,不只是能连上"
3. **设置页整体 UI 重写** —— 现在设置页信息密、分组与适配还没做好
4. **「允许电脑访问」的桌面/手机版切换** —— 字段已在后端,实际切换逻辑尚未完成
5. **未来可能单独制作手机 App 进行连接** —— 但**不会抛弃网页连接方式**,网页会一直保留

## ✨ 上一版以来的其它改进

- **阅读统计页**:实时剧情页上方的「阅读统计」按钮 → 全屏统计页(圆盘图 + 波浪条 + 各游戏排行 + 进出动画 + 数字滚动)
- **永久累计**:关游戏、关软件、重装都不丢,按游戏分开记(`%LOCALAPPDATA%\Lyra\readstats.json`)
- **修复:正常台词被误过滤** —— 台词里出现「商店」「记忆」「设置」这类界面关键词时,整句会被丢掉;现在先认台词(带引号的),面板文字照旧会被拦
- **选择/卡牌界面不再乱点** —— 几秒内连着出现多条短句时判定为选项画面,自动点击暂停 25 秒让玩家自己选
- **统计写盘兜底** —— 直接杀进程也最多只丢最后 1 秒的字
