# Lyra 1.6.0 · 游戏适配 + 跨远程访问(研发中)

> 新增《A Better Tomorrow》适配,并把 **LDC 档位改成"按游戏自动切换"**;
> 跨远程访问仍是**研发中**功能,所以这一版继续以 **Pre-release(预发布)** 发布。

## 🎮 新适配:《A Better Tomorrow》(Unity IL2CPP / TMP)

实测定位到的两个问题,都已修:

1. **对白读不到** —— 原来档位是 `gameonly`,日志显示只挂上 2 个「飘字特效」方法,真正的对白一个没挂。
   换到 `tmpro` 档后挂上 **14 个方法**(`TMP_Text.set_text` / `SetText` / `SetCharArray`…),对白正常读取。
2. **「隐藏」被当成角色名** —— 这是游戏里"隐藏对话框"按钮,却让每条台词变成 `【隐藏】xxx`。
   已加入名字黑名单,台词恢复干净。

新增专用适配档:21 个菜单词(新游戏/继续游戏/设置/退出/存档/历史/自动/隐藏/返回主页…)+ 22 个名字黑名单。

## ⚙️ 档位改成"按游戏切换"

| 游戏类型 | LDC 档位 | 原因 |
|---|---|---|
| UTAGE 系(Knights College 等) | `gameonly` | 它有自己的文本系统,挂 TMP 可能闪退 |
| IL2CPP + TMPro(A Better Tomorrow 等) | `tmpro` | 否则只挂到特效方法,会漏对白 |

匹配到游戏时会**自动切换**并写入 `storyhook_mode.txt`,不用手动改。

## 🚧 研发中(如实说明)

**跨远程访问**已可使用(开关在 设置 → 扩展模块;顶栏「⇄ 跨设备」入口),但仍是半成品:

1. **互动与交互** —— 把电脑上的画面同步到手机(目前只有文字与控制,还没有画面同步)
2. 手机端 UI 继续打磨
3. **设置页整体 UI 重写**(现在信息密、分组与适配还没做好)
4. 「允许电脑访问」的桌面/手机版切换逻辑尚未完成
5. 未来可能出独立手机 App,但**不会抛弃网页连接**
