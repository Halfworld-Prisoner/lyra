## [1.2.0] — 开机动画

### 新增
- **开机动画(splash)**:启动 Lyra 时播放一段约 2 秒的动画 ——
  天琴座(Lyra)星座连线逐条绘制、织女星亮起、星空缓慢漂移,
  随后 Logo 以轻微 3D 摆动着淡入、一道高光扫过,标题「Lyra」逐字升起,底部进度条填满,再淡出进主界面。
  - 灵感来自项目名:天琴座;配色跟随当前主题(暗夜 / 明亮 / 护眼 / MD3 都会自动适配);
  - **点击 / 按键 / 触摸立刻跳过**;识别系统「减少动态效果」设置时不播放;
  - 侧栏新增 **「开机动画」开关**,可永久关闭(状态正常保存);
  - 全程纯 CSS/SVG 实现:不引第三方库、不下载资源、不影响启动速度;
  - 另有 5 秒兜底:无论动画或脚本出什么状况,主界面一定会出现。
- **安装程序 / 卸载程序也加了同款开场动画**(轻量内联版,1.75 秒后自动进入界面)。

### 变更
- 版本号 1.1 → **1.2**。
