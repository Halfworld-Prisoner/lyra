## [1.3.0] — 置顶修复

### 修复
- **窗口置顶一直不生效**(点了开关、配置也存了,窗口却还是会被挡住):
  窗口宿主注册的窗口类名是 `LingYueReaderWindow`(改名 Lyra 时只改了显示名,类名没动),
  而后端找窗口时写死 `FindWindowW("LyraWindow")` → 永远拿到 0 → `SetWindowPos` **根本没被调用**。
  现在改为三级兜底:`已知类名列表` → `按宿主进程枚举顶层窗口(取面积最大)` → `按标题` ,
  以后即使再改类名也不会坏。实测:取消置顶 → 窗口样式真的去掉;重开 → 自动恢复置顶。

### 变更
- **开机动画改为固定流程,去掉开关**(启动即播放,更早开始);
  仍保留:点击 / 按键 / 触摸立刻跳过、系统「减少动态效果」时静态展示。
