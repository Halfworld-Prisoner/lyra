## ⬇️ 下载

| 文件 | 大小 | 说明 |
|---|---|---|
| **`Lyra-Setup-1.1.0.exe`** | 130 MB | **离线安装包** —— 已内置便携 Python 运行环境与男声语音包,安装过程**不需要联网** |

> 同一个 exe 装好之后双击就是启动器;静默安装:`"Lyra-Setup-1.1.0.exe" --install D:\Lyra`

## 🎬 四步上手

1. **双击安装包** → 选目录(默认 `D:\Lyra`,可改;C 盘/U 盘都行)→ 点「开始安装」
2. 打开 Lyra → 在游戏卡片上点 **「安装 LDC」**(给这款游戏接上文字挂钩,**不改游戏文件**)
3. 点 **「启动游戏」** → 进游戏看到对话,它就开始念了(悬浮窗可随时暂停)
4. 想要中文:游戏卡片上点 **「安装翻译」** → 打开翻译开关 → **重启游戏**

## ✨ 它能做什么

| | |
|---|---|
| **实时剧情朗读** | 直接读游戏文本接口,**不截图、不 OCR**;语速 / 音高 / 音量可调 |
| **角色配音** | 按说话人自动换音色,每个角色单独指定声音 |
| **离线语音包** | 内置男声「超文」,全部本机推理;可再下载更多男声 |
| **文本翻译** | 接入任意 OpenAI 兼容接口(默认 DeepSeek),只替换外文,译文可写回画面 |
| **过滤与名单** | 界面文字自动不念;日志里点一句即可加白/拉黑,AI 也能代你加过滤词 |
| **自动下一句** | 念完自动推进剧情,**静默方式不动鼠标**,失败自动回退点击 |
| **悬浮窗 / 四套主题** | 置顶小条显示状态与台词;暗夜 / 明亮 / 护眼 / Material 3 |

## 🐞 本版修复了什么

| 问题 | 现在 |
|---|---|
| 关掉翻译后游戏里仍是中文 | 改为**服务端总开关**,并清掉 XUnity 自己那份「原文=原文」的毒缓存 |
| 开了翻译游戏里还是原文 | 打开开关时同步写入接口地址与字体设置;**重启游戏即生效** |
| 游戏运行时打不开开关(`WinError 1224`) | 内容相同就跳过复制;确实被占用时提示「先退出游戏」 |
| 角色名残留繁体(格蘭特尼 / 奧斯卡) | 换成 **OpenCC 权威简繁表(4148 条)** + 短名字本地直转(不花 token) |
| 译文丢符号(「」《》—— ♪ 等) | 符号清单写进提示词 + 短句缺符号自动重试;**接口永不返回空**,不再出现满屏「翻译失败」 |
| 翻译很慢 / 频繁失败 | 每句只打一次 AI(之前会打 2~3 次),实测约 **1 秒/句** |
| 台词出现方框字(□) | 自动把游戏字体指向系统中文字体(可关) |
| AI 的 Key 保存后变成空的 | 输入框加「脏值保护」,保存成功前不会被界面刷新覆盖 |
| AI 报错看不懂 | 按 401 / 404 / 429 / 5xx / 超时分别给出人话 |
| 卸载点了确认没反应 | 修复自删除流程;不再多弹结果窗口 |
| 安装器 Logo / 路径框 / 滚动条 | 全部修好;安装器与卸载器改为**网页界面**,环境缺失时自动回退 |

## ⚠️ 已知问题

- **部分游戏的主菜单按钮**(如 `START / LOAD / CONFIG / GALLERY`)经日志确认**不是文字组件**,而是图片/精灵,
  文字翻译无法覆盖;后续可能以贴图替换或悬浮层方式处理。
- `Knights College 2`、`Astatos` 的剧情文本尚未接入挂钩(需单独做引擎适配)。
- **请勿在已安装 Lyra 的目录上反复点「重新安装」**(会覆盖设置);正式修复见下一版。
