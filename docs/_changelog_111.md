## [1.1.1] — 状态保存与兼容性修复

### 修复
- **设置页开关重启后全显示为「关」**(其实功能在跑):前端只有翻译页写了「配置 → 界面」的渲染,
  设置页的开关**从来没有从配置读回**。现在补齐 `renderSettings()`(开关 / 数值 / 下拉全部同步),
  并给刚点过的控件 1.2 秒保护期,不与玩家操作打架。
- **默认配音选女声,重启后被改回全局默认**:`migrate_voice_cfg()` 是女声下架时写的一次性迁移,
  却每次启动都跑,会把 `cast_default` 与角色配音里的女声清空。现在只在**声音 id 已失效**时清理,
  玩家选的女声原样保留。
- **兼容性:去掉对 `libwinpthread-1.dll` 的依赖**。`Lyra.exe`(窗口宿主)、安装程序、卸载程序
  原先依赖 MinGW 的这只运行库,没装过 MinGW 的电脑会「双击没反应」。三个 exe 改为**全静态链接**
  (`-static`),现在只依赖系统 DLL。
